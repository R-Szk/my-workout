# My Workout — 自宅トレーニング用3ステップ画像

可変式ダンベルと自重を使うA/Bメニュー6種目、合計18枚の透過PNGです。

## 収録内容

| メニュー | 種目 | ディレクトリ | ステップ |
| --- | --- | --- | --- |
| A | プッシュアップ | `exercises/push_up/` | 高い姿勢 → 途中 → 胸を下ろす |
| A | サイドレイズ | `exercises/lateral_raise/` | 腕を下ろす → 斜めに上げる → 肩の高さ |
| A | トライセプスエクステンション | `exercises/triceps_extension/` | 肘を曲げる → 途中 → 頭上に伸ばす |
| B | ワンハンド・ダンベルロー | `exercises/one_arm_row/` | 腕を下ろす → 途中 → 体側に引く |
| B | ダンベルカール | `exercises/dumbbell_curl/` | 腕を下ろす → 途中 → 肘を曲げる |
| B | スクワット | `exercises/squat/` | 直立 → 途中 → しゃがむ |

すべてのディレクトリに `step_1.png` / `step_2.png` / `step_3.png` が入っています。アニメーション再生や画像の変形は不要です。

## Codex向け組み込み指示

1. まずこのディレクトリと全18枚を確認する。
2. 画像をAndroidアプリの適切な画像リソースへ取り込む（透過を維持する）。
3. 各種目の画面で `step_1` → `step_2` → `step_3` を左から右へ並べる。モバイル画面に収まらない場合は横スクロールにする。
4. 縦横比を維持し、画像を切り抜かない。特にプッシュアップ・ワンハンドローは横長の構図に注意。
5. 既存の滑らかなループアニメーションはこの画面では使わない。
6. 既存の筋肉マップ、記録機能、A/Bメニュー、保存データは維持する。

`manifest.json` に、各種目のID・日本語名・画像パスを記載しています。

注：画像は生成された説明用イラストです。すべての細部が専門家によるフォーム検証済みという意味ではありません。公開前には動作説明との整合性を確認してください。
