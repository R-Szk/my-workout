## 実装上の判断

- 順番変更は全種目IDの置換順序を検証し、Roomトランザクション内で一時位置へ移動してから確定する。現在表示している種目はIDで維持する。
- スキップは未実施として区別。保存済みセットがある場合はスキップを拒否し、セット取り消し後に可能とする。誤操作に備えてスキップ解除も提供する。
- スキップ時は次の未スキップ種目（なければ前のもの）へ進み、全部スキップでも有効な位置を維持。
- 追加種目は末尾へコピー。同じマシンを別種目として追加可能。目標は同メニュー内の既存テンプレートを使い、それがなければ編集用初期値の2セット・10回を使用。既存の入力位置は維持し、全種目スキップ時だけ追加種目へ移動する。
- 過去セッションとA/Bテンプレートは書き換えない。完了済み・中断中のセッション編集を拒否する。
- DB v3は種目状態の列を追加し、v2→v3の自動移行で既存行をPENDINGとする。v1からの移行も維持する。
