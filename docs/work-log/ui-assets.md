## 実装と確認

- Material 3のダークテーマ、ホーム、常時表示の画像列、前回全セット、＋／－と直接入力、固定保存ボタン、完了画面を実装。既存の保存・取消・順番変更・スキップ・追加・再開を維持。
- 集計はRoomの終了済み実績から取得。空セッションと未実施種目を除外し、同種目・同重量の回数を比較。補助重量は通常負荷と区別。月間の実施日と実施回数も実データを使用。
- 29機種のメタデータを対応付けたが、既存9機種とA/Bを自動変更しない。画像はFit表示、欠落時は機種名とプロフィール由来の筋肉図で代替。
- 原素材を検査し、ロー2図（seated_row_plate_loaded、incline_lever_row）で主筋群の赤が補助領域に隠れていることを確認。該当図は提供SVG由来の人体輪郭から主赤・補助オレンジで描画。可変種目もプロフィールから描画する。全29種目の医学的精密図を保証するものではない。

## テスト駆動とレビュー

初期のカタログ・前回記録・集計・入力調整テストの失敗後に実装し、成功を確認。
レビューで検出された以下3件は、失敗するテストを追加して修正した。

1. ローの主筋群の赤が見えない: 実スクリーンショットの赤／オレンジ画素検査で再現し、派生図で解消。
2. 各日の最大重量を選ぶと同重量回数の記録が失われる: 元セットから回数系列を別集計し、混合重量の単体テストで確認。
3. 低い画面で固定領域が入力を押し出す: 230dp高のAndroidテストで再現。低い画面専用の小さなヘッダー・画像列とスクロール配置で解消。

v3の実ファイルDBからの移行で編集名・中断位置・スキップ・既存セットを保持。旧未分類の記録がある種目も分類を強制せず記録継続できることを確認。
連打・画像常時表示・実績サマリー・既存の記録フローと種目編集の回帰テストも成功。
