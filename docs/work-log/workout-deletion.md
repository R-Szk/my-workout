# 履歴からワークアウトを削除

2026-11-11

- 履歴一覧の各ワークアウトに「削除」を追加。日時・メニュー・セット数を確認して「削除する」を押すと削除。キャンセルでは変更しない。取り消せない操作であることを確認画面へ表示する。
- WorkoutSessionDaoに完了済みかつactiveSlotがnullのセッションだけを削除する条件付きSQLを追加。既存の外部キーCASCADEで対象の種目・セットも削除し、他の履歴、カタログ、進行中／中断中のセッションは保持。DBスキーマ変更なし。
- Repositoryから削除結果を返し、WorkoutViewModelで処理中の重複操作・失敗表示を扱う。削除後は履歴のRoom Flowと未完了セッションを再読み込みし、実施回数・成長グラフ・前回の提案値にも反映する。
- 履歴と確認ダイアログを同時表示しない。削除対象がなくなった場合は履歴を表示できるようにし、画面再生成後にも古い確認対象IDで操作が塞がらないようにする。

## 検証

- 単体テストを先に作成し、未実装APIで失敗することを確認。
- WorkoutDeletionTest：対象種目・セットの連鎖削除、他履歴・カタログ・中断記録の保護、削除の再実行、前回値の繰り上げ、最後の履歴を削除した場合の集計を検証。
- WorkoutDeletionFlowTest：確認・キャンセル・削除・他履歴保持・再生成後の反映、確認対象消失時の復帰を検証。
- 単体60件、Android全28件成功。確認対象消失ケースの追加後、削除フロー1件も再実行して成功。
- Debug／ReleaseビルドとLint成功。Lintエラー0・警告30件。
- レビューの確認対象消失時の復帰に関する指摘を修正し、Androidテストで確認。
- エミュレーターの元データを復元。実機Galaxyにも記録を保持して更新し、通常画面の正常起動を確認。実機の既存履歴は削除していない。
