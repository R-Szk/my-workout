# 未実施の履歴除外と、中断を除く経過時間

2026-11-11

## 仕様と実装

- 実施セットが0件のまま終了した場合、完了サマリーを表示せずホームへ戻る。「セットが未記録のため、記録を残さず終了しました。」と表示する。保存済みセットをすべて取り消した場合も同じ。
- `WorkoutSessionDao.observeHistory` は、スキップ以外の種目に実際のセットがある完了セッションだけを返す。既存の空セッションも履歴・集計から除外。セッション管理用のDB行は保持するがトレーニング実績には数えない。記録済みセット・既存履歴を削除しない。
- `SessionController.finish` は実施実績の有無を返し、`WorkoutViewModel` がサマリーへの遷移を切り替える。
- `WorkoutSession.activeDurationMillis` と `activeStartedAt` を追加。開始時に0から計時し、中断時に実施区間を加算、再開時に次の区間を開始。中断の重複、実施中の再開、終了の重複は計時に影響させない。中断したまま終了した場合も中断時間を含めない。
- Room v6、非破壊の自動マイグレーション5→6。積算時間と区間開始時刻をDBに保持し、コントローラー・Activityの再生成後にも継続。
- 過去の記録には中断区間の情報がないため、新しい計時項目はnullのまま移行する。旧記録・移行時点の中断記録は経過時間を「未計測」と表示し、日時・セット・実績を保持。開始から終了までの時間を実施時間として推測表示しない。
- 画像、種目、セット番号・編集・再開・メニュー選択は維持。

## 検証

- 先にWorkoutTimingTestを追加し、未実装API・返却値で失敗することを確認。
- 単体テスト：空終了、全セット取り消し後の終了、複数回中断、再開重複、コントローラー再生成、終了重複、中断したまま終了を固定時刻で確認。
- Androidテスト：未実施で終了→ホーム→再生成後も履歴が増えないこと、v5の完了／空／中断データをv6へ移行し実績保持・空履歴除外・旧時間未計測になることを確認。
- 単体57件、Android27件すべて成功。assembleDebug / assembleRelease / lintDebug成功、Lintエラー0・警告30件。
- 初回Android実行で0件終了に対する旧期待値と、背後の入力欄を含める不安定な編集テストを修正。再実行で全件成功。
- 非破壊移行・計時・履歴除外について読み取りレビューで重大な指摘なし。
- エミュレーターの元データを復元。実機Galaxyにも記録を保持して更新インストール。
